# spec-delta: 404-page

## MODIFIED Requirements

### Requirement: [404-02] Visual Consistency and Accessibility
The 404 page MUST be visually consistent with the rest of the site and adhere to accessibility standards, maintaining a focused viewport presence.

#### Scenario: Styling and Layout
- **GIVEN** the 404 page is rendered.
- **THEN** it MUST be centered horizontally and vertically within the `main` content area.
- **AND** it MUST have a minimum height of `100vh` (e.g., `min-h-screen`) to maintain focus.
- **AND** the typography MUST use the standard brand fonts (Epilogue and Inter).
- **AND** the background MUST use the brand's dark background color (`bg-brand-background`).
